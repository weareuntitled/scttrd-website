# Definition of Done

„Done" muss für alle dasselbe bedeuten. Viele Probleme entstehen nicht, weil nichts getan wird,
sondern weil Aufgaben zu früh als erledigt gelten.

| Aufgabe | NICHT „done" | Wirklich „done" |
|---|---|---|
| **Booking-Mail** | Mail einmal verschickt | Empfänger geprüft, Links aktuell, Rider aktuell, Mail geprüft, versendet, Follow-up gesetzt, Antwort dokumentiert |
| **Reel** | Video geschnitten | Video fertig, Caption/Copy vorhanden, freigegeben, in Metricool eingeplant |
| **Track** | „Klingt fast fertig" | Feedback beendet, Production Freeze, Rough Mix, Mix/Master, Revision abgeschlossen, finale Datei abgelegt |
| **Rider** | PDF existiert | Inhalt aktuell, Version klar benannt, zentrale Ablage aktuell, nur diese Version wird verschickt |

## Ownership-Regel

„Ich kümmere mich darum" bedeutet: **selbstständig Entwurf erstellen, offene Punkte identifizieren,
gezielt Input einholen, finalisieren, Update geben.** Nicht: auf einen gemeinsamen
Vier-Stunden-Call warten.

## Meeting-Regel

Kein Punkt endet mit „müssten wir mal". Jeder relevante Punkt endet mit
**Entscheidung · Owner · Deadline · nächstem konkreten Schritt.**
